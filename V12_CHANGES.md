# Tayyib Word v12 — Feature Completion Pass

This version builds on v11 and closes several remaining functional gaps without pretending to be a full Microsoft Word engine.

- Real theme and font-set application (Office/Classic/Modern/Minimal)
- Persistent theme/font-set/chart data/SmartArt data/footnotes/endnotes/mail-merge records
- Functional footnote/endnote insertion and document display
- Heading-based table-of-contents generation from simple heading conventions
- Functional mail-merge preview and Finish Merge for NAME/EMAIL fields
- Index-entry marking
- Editable chart data
- Configurable table style (Table Grid / Light Shading / No Borders)
- First-page and odd/even header/footer handling in PDF and DOCX section settings
- Picture left/center/right placement based on wrap setting
- DOCX footnote/endnote text export
- TWD document format version 4 while retaining backward loading

Still inherently limited compared with Microsoft Word: a full pagination/layout engine, true OOXML round-trip editing, native revision markup, threaded comments, true floating drawing layer, true SmartArt/Chart editors, full table merge/split, VBA/macros, collaboration/cloud, and the complete Word object model.
